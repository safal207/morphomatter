## Experiment 032 — Counterfactual Material Scientist

Goal: add causal intervention reasoning.

Instead of only asking:

"What happened?"

ask:

"What would happen if we changed X?"

Architecture:

Observation
↓
Causal model
↓
Intervention
↓
Predicted outcome
↓
Experiment
↓
Update model

Examples:
- change interface affinity;
- change particle property;
- change environment;
- change geometry.

Core principle:

`correlation -> intervention -> causal understanding`
