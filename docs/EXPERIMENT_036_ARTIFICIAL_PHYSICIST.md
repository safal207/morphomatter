# Experiment 036 — Artificial Physicist

## Goal

Create a research loop where the system does not only optimize materials, but proposes, tests, and revises explanatory laws.

The target cycle:

```
Observation
    ↓
Hypothesis generation
    ↓
Mathematical model
    ↓
Prediction
    ↓
Virtual experiment
    ↓
Falsification attempt
    ↓
Improved theory
```

## Core idea

A useful material discovery system needs more than prediction. It needs causal explanations that survive interventions.

Model:

```
Material state
+ Environment
+ Interaction field
+ History
        ↓
Causal theory
        ↓
Predicted transition
        ↓
Experiment
```

## Components

### 1. Theory generator

Produces candidate transition rules:

- interaction laws;
- phase boundaries;
- causal graphs;
- scaling relations.

### 2. Prediction engine

Tests whether a proposed law predicts:

- nucleation;
- frontier growth;
- stability;
- hysteresis;
- recovery.

### 3. Falsification engine

Searches for experiments where the current theory could fail.

### 4. Theory memory

Stores:

- successful explanations;
- failed hypotheses;
- known limits;
- transfer between material classes.

## Metrics

- predictive accuracy;
- causal accuracy;
- number of experiments needed to discover a rule;
- generalization to unknown materials;
- simplicity of discovered explanations.

## Interpretation boundary

This is a research architecture concept for synthetic material discovery. It does not claim autonomous scientific discovery in physical materials without calibrated experiments.
