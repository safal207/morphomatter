# Experiment 039 — Causal Field Theory

## Goal

Move from discrete causal edges:

`A → B`

into a distributed causal field:

`C(x,t,phase)`

where causal influence exists across space, time and phase coordinates.

## Core hypothesis

Complex transitions are not controlled by one cause. They emerge from a changing landscape of causal influence:

```
Material properties
        ↓
Interaction field Φ(x,t)
        ↓
Causal field C(x,t,φ)
        ↓
Transition dynamics
        ↓
Structure
```

## Causal field representation

Each region contains:

- active causes;
- influence strength;
- time delay;
- uncertainty;
- phase dependence.

Example:

```
t0:
Environment → nucleation

 t1:
Nucleation → frontier growth

 t2:
Internal structure → stability
```

The dominant cause can change during the transition.

## Research questions

1. Can causal influence be represented as a continuous field?
2. Do causal patterns form stable attractors?
3. Can the field predict the next transition event?
4. Does causal structure scale from micro to macro levels?

## Metrics

- causal prediction error;
- transition forecasting accuracy;
- causal stability;
- transfer across materials;
- scale consistency.

## Architecture extension

```
State
 ↓
Interaction Field Φ(x,t)
 ↓
Causal Field C(x,t,φ)
 ↓
World Model
 ↓
Intervention
```

## Interpretation boundary

This is a conceptual research architecture for synthetic transition systems. It does not claim a discovered physical field or a new fundamental theory.
