# Experiment 037 — Law Compression / Minimum Description Length

## Goal

Find whether different materials and transition systems can be explained by shorter shared rules instead of isolated descriptions.

## Core hypothesis

A useful scientific law compresses many observations:

```
Many systems
      ↓
Shared transition grammar
      ↓
Compact causal model
      ↓
New predictions
```

## Principle

Use a Minimum Description Length style objective:

```
Total description = model complexity + unexplained observations
```

A better law explains more systems with fewer assumptions.

## Inputs

- Material properties
- Environment properties
- Interface parameters
- Interaction fields
- Transition trajectories
- Causal graphs
- Fractal signatures

## Discovery loop

```
Observe systems
      ↓
Extract transition patterns
      ↓
Generate candidate laws
      ↓
Compress explanation
      ↓
Test on unseen systems
      ↓
Update law library
```

## Metrics

- compression ratio;
- predictive accuracy;
- transfer to unseen materials;
- causal simplicity;
- robustness across scales.

## Research question

Do apparently different materials share a hidden transition language?

## Interpretation boundary

This is a research architecture for synthetic discovery. It does not claim discovery of a physical universal law without calibrated experiments.
