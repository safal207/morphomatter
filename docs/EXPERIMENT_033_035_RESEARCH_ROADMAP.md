# Experiment 033-035 Research Roadmap

## Experiment 033 — Universal Transition Language

Goal: discover reusable transition motifs across different synthetic materials.

Hypothesis:

```
Different materials
        ↓
Different microscopic rules
        ↓
Similar transition grammar
```

Represent transitions as sequences:

```
nucleation → growth → competition → stabilization
```

The objective is not to classify materials only, but to discover whether different systems share common transition patterns.

---

## Experiment 034 — Transition Grammar Discovery

Build a symbolic representation of phase changes:

```
State
 ↓
Cause
 ↓
Interaction change
 ↓
Structural event
 ↓
New state
```

Possible learned primitives:

- nucleation event;
- frontier propagation;
- defect healing;
- attractor capture;
- stabilization.

The AI searches for minimal explanations of observed transitions.

---

## Experiment 035 — Universal Material Embedding

Create a latent space:

```
Material properties
Environment
Interaction rules
Transition history
        ↓
      Embedding
        ↓
Similarity of transition behavior
```

Questions:

- Do different materials cluster by transition behavior?
- Can unknown materials inherit knowledge from known systems?
- Are there universal classes of self-organization?
